ChurnIQ PNG Icon Pack

All icons are 512 x 512 PNG files with transparent backgrounds.
Use the title_telecom_tower icon larger beside the dashboard title.
Use nav_* icons on navigation buttons, kpi_* icons on KPI cards,
and chart_* icons beside chart titles.

Suggested display sizes:
- Main title icon: 48–64 px
- Sidebar navigation icons: 18–22 px
- KPI icons: 20–24 px (optionally inside a 40–44 px pale circle)
- Chart title icons: 18–22 px

The nav icons are white for the dark navy sidebar.
